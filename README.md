# Portfolio

This is a portfolio for myself, [Ian Rodriguez](https://github.com/ianro04).
It was written using the [Angular framework](https://angular.dev/overview), and new iterations of it are deployed to GitHub Actions using [this Action](https://github.com/jamesives/github-pages-deploy-action).

You can visit the site [here](https://ianro04.github.io/).

## Dependencies Used

- [Angular Material](https://material.angular.dev/)
- [Cashew](https://www.npmjs.com/package/@ngneat/cashew)
- [NGX Extended PDF Viewer](https://pdfviewer.net/extended-pdf-viewer/)
- [Taiga UI](https://taiga-ui.dev/)
